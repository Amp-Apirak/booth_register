ขั้นตอนการจัดงาน (Workflow Timeline)

1
ขั้นตอนก่อนวันงาน
รับ Link / QR ประชาสัมพันธ์
ผู้เข้าร่วมสแกน QR Code จากบัตรเชิญ อีเมล สื่อสังคมออนไลน์ หรือหน้าเว็บไซต์โครงการ
2
ขั้นตอนก่อนวันงาน
ลงทะเบียนเข้าสู่ระบบ (Online Registration)
กรอกข้อมูลส่วนตัว: ชื่อ-นามสกุล, บริษัท, ตำแหน่งงาน, อีเมล, เบอร์โทรศัพท์ผ่านสมาร์ทโฟน
3
ขั้นตอนก่อนวันงาน
รับตั๋วผ่านประตู (Event QR Code)
ระบบจะทำการ Generate รูปภาพ QR Code ลิงก์ข้อมูลส่วนบุคคลส่งให้ผู้ร่วมงานทันที
4
ขั้นตอนวันงาน
แสดง QR Code สแกนเข้างาน
ผู้ร่วมงานเปิดรูปภาพ QR Code (Event Pass) บนสมาร์ทโฟนของตนเองเมื่อเดินเข้ามาถึงจุดประตูงาน
5
ขั้นตอนวันงาน
เจ้าหน้าที่สแกน Check-in รวดเร็ว
เจ้าหน้าที่ใช้อุปกรณ์สแกนบาร์โค้ดสแกนหน้าจอ เพื่อส่งข้อมูลสถานะเช็คอินเข้าคลาวด์ดาต้าเบสแบบเรียลไทม์
6
ขั้นตอนวันงาน
แสดงผลต้อนรับขึ้นจอใหญ่แบบทันใด
ระบบ Digital Signage CMS ดึงข้อมูลผ่าน WebSocket แสดงผลชื่อและกราฟฟิกต้อนรับสวยงามขึ้นจอ LED ทันที

สรุปเชิงสถิติ: จากเป้าหมายลงทะเบียน 320 คน ระบบสามารถตรวจทานเช็คอินสำเร็จ 245 คน ในวันจัดงานจริง คิดเป็น Show-up Rate 76% โดยระยะเวลาเช็คอินเฉลี่ยต่อคนเร็วกว่า 5 วินาที ทำให้ได้คะแนนพึงพอใจการใช้ตั๋วดิจิทัล (CSAT) สูงถึง 4.6 จาก 5.0 คะแนน

ประโยชน์ที่องค์กรจะได้รับ (Business Value)

เลิกการจัดทำเอกสารกระดาษหน้างาน 100% ลดการสะกดชื่อผิดพลาดของผู้เข้าร่วม

เช็คอินด่วนพิเศษ (Fast-track check-in)

✓

ข้อมูล Sync สดใหม่ทันเวลา

ผู้บริหารตรวจสอบสถิติจำนวนคนสะสมแบบรายวินาที และวิเคราะห์ประสิทธิภาพวันงานได้ทันที

✓

เพิ่มข้อมูลผู้เข้าร่วมงาน

ฐานข้อมูลผู้ร่วมงานจำลอง (Live Mock Database)

ชื่อ - นามสกุล บริษัท / ตำแหน่ง อีเมล / เบอร์โทร สถานะ การจัดการ

สมาร์ทโฟนผู้เข้าร่วมงานจำลอง (Participant Mobile Simulator)

ทดลองจำลองมุมมองฝั่งผู้ใช้: ทำการลงทะเบียนผ่านโทรศัพท์และระบบจะออกแบบฟอร์มคิวอาร์โค้ดเข้างานเพื่อนำมาใช้จำลองสแกน

💡 วิธีการสาธิตการทำงาน (Interactive Walkthrough Steps):

  1. ขั้นที่ 1: กรอกข้อมูลลงทะเบียนในแบบฟอร์มบนหน้าจอโทรศัพท์จำลองทางซ้าย และกดปุ่ม "ลงทะเบียนออนไลน์"
  2. ขั้นที่ 2: หน้าจอโทรศัพท์จำลองจะเปลี่ยนเป็นหน้า "ตั๋วดิจิทัล (Event Pass)" ทันที โดยมีสถานะสีส้มเขียนว่า "รอดำเนินการ (Pending)"
  3. ขั้นที่ 3 (สแกนรับสิทธิ์): - คุณสามารถกดปุ่ม "จำลองการยิงสแกน QR Code นี้" ใต้ตั๋วบนหน้าจอมือถือได้ทันที - หรือหากเปิดเซิร์ฟเวอร์จำลองไว้ ให้เปิดสไลด์นำเสนอแท็บ *"จัดการข้อมูลผู้ร่วมงาน"* อีกหน้าต่างนึง จะพบว่ามีชื่อนี้เพิ่มเข้ามาใหม่ และเมื่อคุณกดเครื่องหมายถูก (เช็คอิน) จากแผงแอดมิน: - **ผลลัพธ์**: สถานะตั๋วบนโทรศัพท์จำลองจะสลับเป็นสีเขียว "เช็คอินสำเร็จ" พร้อมเล่นเสียงสัญญาณ Beep เตือน และบอร์ดแดชบอร์ด/จอ LED Welcome ใหญ่จะขยับขึ้นชื่อต้อนรับพร้อมกันทันที!

🛡️

ผู้จัดงานหลัก (Super Admin)

ดูแลความเรียบร้อยของงาน จัดการการตั้งค่า และวิเคราะห์ข้อมูลในระดับสูงสุด

  • สิทธิ์จัดการข้อมูล สปอนเซอร์ กำหนดการ และบัญชีสตาฟ
  • ควบคุมและสลับการแสดงหน้าจอ Signage 8 รูปแบบ
  • วิเคราะห์รายงาน แดชบอร์ดสถิติสด และรัน Lucky Draw
🔍

เจ้าหน้าที่จุดตรวจ (Staff / Checker)

ผู้ปฏิบัติงานหน้าเคาน์เตอร์ ณ จุดเข้างาน เน้นการทำงานรวดเร็วแบบเชี่ยวชาญ

  • สแกนเช็คอิน QR Code บัตรเข้างานด้วยความเร็วสูง
  • ค้นหา คัดกรอง และดูรายชื่อ ตรวจสอบสถานะการลงทะเบียน
  • จัดการแก้ไขโปรไฟล์พื้นฐานเมื่อมีข้อมูลพิมพ์ผิดหน้างาน
📱

ผู้เข้าร่วมงาน (Participant / Guest)

ผู้รับบริการหลักของงานอีเวนต์ สื่อสารผ่านสมาร์ทโฟนของตนเอง

  • สแกนลงทะเบียนด้วยตนเอง (Self-Registration)
  • แสดง QR Code ประจำตัวเพื่อสแกนยืนยันผ่านประตู
  • ร่วมกิจกรรม เล่นเกม ตอบแบบประเมิน CSAT ชิงรางวัล

คู่มือการวางโครงร่างเมนูหน้าเว็บ (Menu Wireframe Outlines)

🖥️ ระบบหลังบ้านหลัก (Admin & Staff Viewport)
  1. แถบเมนูข้าง (Sidebar): ปุ่มแดชบอร์ด, จัดการผู้ร่วมงาน, เมนูสแกนเนอร์สตาฟ, ป้ายสวิตช์จอSignage, เมนูสุ่ม Lucky Draw, ข้อมูลสปอนเซอร์ & กำหนดการ
  2. แถบควบคุมบน (Top Bar): บัญชีเจ้าหน้าที่ที่ใช้งาน, ลิงก์สลับเข้าสู่หน้าจอ Signage และฟังก์ชันแจ้งเตือน (Notifications)
  3. หน้าต่างหลัก (Content Panel): แสดงกราฟิก ตารางรายชื่อ หรือฟอร์มกรอกข้อมูลตามเมนูที่เปิดเลือก
📱 ระบบเว็บแอปมือถือผู้เข้าร่วม (Participant Mobile Viewport)
  1. หน้าต่างเดี่ยว (Single View Container): เน้นความกระชับ แสดงผลพอดีหน้าจอมือถือโดยไม่ต้องเลื่อนยาว
  2. หน้าบัตรคิวอาร์ (My Ticket Pass Card): ออกแบบในลักษณะบัตรผ่านประตูดิจิทัล (Wallet Pass) แสดง QR โดดเด่น ชัดเจน ตรวจสอบความสว่างหน้าจออัตโนมัติเพื่อให้เครื่องสแกนบาร์โค้ดอ่านง่าย
  3. หน้าร่วมกิจกรรม (Engagement Action Panel): ฟอร์มประเมินดาว 5 ดวงพร้อมช่องรับความคิดเห็นสั้นๆ และแจ้งเตือนตารางการจับรางวัลนำโชค

พจนานุกรมข้อมูล (Data Dictionary Overview)

1. EVENT Table

ตารางสำหรับระบุสัญญางานอีเวนต์หลัก สามารถรองรับการขยายระบบไปเป็นแบบ Multi-Event ในอนาคต

2. PARTICIPANT Table

ตารางเก็บรายชื่อผู้ลงทะเบียน `ticket_code` คือรหัสสติกเกอร์/UUID ที่แสดงในรูปแบบ QR Code ใช้ในการอ้างอิงตอนแสกนเช็คอินเข้างาน (1 Event Pass/คน)

3. CHECKIN Table

ตารางบันทึกการแสกนเช็คอินจริง มีข้อกำหนด `UK (Unique Key)` บน `participant_id` เพื่อบังคับสิทธิ์การเข้าใช้งานได้เพียง 1 ครั้งต่อคน (ป้องกันการนำ QR Code ให้ผู้อื่นสแกนซ้ำ)

4. USER (STAFF) Table

จัดเก็บบัญชีผู้ใช้งานฝั่งระบบของ Admin และ Staff ประจำแต่ละช่องสแกน เพื่อระบุประวัติย้อนหลัง (Audit Log) ว่าใครเป็นผู้ทำการผ่านสิทธิ์ผู้เข้าร่วมงานคนใด

5. LUCKY_DRAW_WINNER Table

จัดเก็บรายชื่อผู้สุ่มได้รางวัล `UK (Unique Key)` บน `participant_id` ป้องกันการสุ่มรับรางวัลซ้ำซ้อนของผู้ชนะคนเดิม โดยจะสุ่มดึงจากผู้ที่มีบันทึกในตาราง `CHECKIN` เท่านั้น
