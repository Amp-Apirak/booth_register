# Signed Token Hashing for QR Tickets

เพื่อป้องกันการลอกเลียนแบบตั๋ว ปลอมแปลงสิทธิ์การเข้างาน และคุ้มครองข้อมูลส่วนบุคคลตามกฎหมาย PDPA เราตัดสินใจใช้เทคนิคการถอดรหัสผ่านลายเซ็นดิจิทัล (Signed Token Hashing) ใน QR Code บนตั๋วของผู้สมัคร โดยกุญแจลับ (Secret Key) จะถูกเก็บไว้ฝั่งเซิร์ฟเวอร์เท่านั้น

## Status
accepted

## Considered Options
- **Plaintext UUID**: สุ่มคีย์ UUID แม้จะเดายากแต่หากคนอื่นลอกภาพ QR Code ก็แฝงสิทธิ์เข้างานได้ทันที
- **Plaintext Email/Phone**: ไม่ปลอดภัยเรื่อง PDPA เนื่องจากบุคคลอื่นแสกนแล้วสามารถเห็นข้อมูลส่วนตัวได้ตรงๆ
- **Signed Token Hashing (Selected)**: เข้ารหัสลับและผูกลายเซ็นดิจิทัล ปลอดภัยสูงสุด
