# 0013-theme-and-language

ระบบมี 2 ภาษา (ไทยเป็นค่าเริ่มต้น, อังกฤษ) และ 2 ธีม (มืดเป็นค่าเริ่มต้น, สว่าง) สลับได้จากปุ่มบนเมนูทุกหน้า · ค่าที่เลือกเก็บใน cookie `booth_lang` / `booth_theme` (อายุ 1 ปี) ซึ่ง root layout อ่านฝั่ง server · URL `?lang=en` / `?theme=light` ใช้บังคับค่าและจำไว้ (สำหรับจอ LED หรือ kiosk)

**เหตุผล:**
1. อ่าน cookie ฝั่ง server จึงแสดงภาษา/ธีมถูกตั้งแต่ภาพแรก ไม่กะพริบ · ผลคือทุก route เป็น dynamic (`ƒ`) ซึ่งเครื่อง server แบบ standalone รองรับอยู่แล้ว
2. ข้อความอยู่ในพจนานุกรม `client/src/i18n/th/<เรื่อง>.ts` (ต้นฉบับ) และ `en/<เรื่อง>.ts` ซึ่งประกาศ type เป็น `typeof` ของไฟล์ไทย ถ้าลืมแปล key ใด `tsc` จะ error · ข้อความที่มีตัวแปรใช้ฟังก์ชัน เช่น `usage(n)` · ใช้ผ่าน `useT()` หรือ `usePreferences()`
3. ธีมสว่างไม่ได้เขียน class ใหม่ทุกหน้า: `scripts/gen-theme-light.mjs` สร้าง `src/app/theme-light.css` ที่เปลี่ยนค่าตัวแปรสีของ Tailwind เมื่อ `data-theme="light"` — สีกลาง (slate, gray …) กลับด้าน, สีเน้นระดับ 50–400 เปลี่ยนเป็นระดับเข้มให้อ่านบนพื้นขาวได้, 500–700 คงเดิม, `text-white` กลายเป็นหมึกเข้ม
4. ตัวช่วยเพิ่ม: `text-on-accent` (ตัวอักษรขาวบนปุ่มสีเสมอ), `bg-surface*` (พื้นผิว), `.theme-fixed` (ส่วนที่ห้ามกลับสี เช่น การ์ด QR, กรอบกล้อง), `.theme-print` (บังคับโทนสว่างให้รายงาน A4)

**ผลกระทบ:**
- หน้าใหม่/ข้อความใหม่: เพิ่ม key ในไฟล์ไทยก่อน แล้วแปลในไฟล์อังกฤษ ห้ามพิมพ์ข้อความลงใน JSX ตรง ๆ
- ปุ่มพื้นสีทึบให้ใช้ `text-on-accent` แทน `text-white` (ดู `scripts/codemod-on-accent.py`)
- อัปเกรด Tailwind แล้วให้รัน `node scripts/gen-theme-light.mjs` ใหม่
- ไม่แปลอัตโนมัติ: ข้อมูลจากฐานข้อมูลที่ผู้จัดกรอก (ชื่องาน, กำหนดการ, ของรางวัล, ข้อความหน้าลงทะเบียน) · ประเภทองค์กรมีช่องชื่อภาษาอังกฤษแยก
- ข้อความ error จาก server บางจุดในหน้าเจ้าหน้าที่ยังเป็นภาษาไทย (หัวข้อแจ้งเตือนแปลแล้ว) — หน้า login และหน้าประเภทองค์กรแปลตามรหัส error แล้ว
