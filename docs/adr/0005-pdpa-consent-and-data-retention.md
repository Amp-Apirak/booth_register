# PDPA Consent and Indefinite Data Retention for Marketing

เพื่อความเป็นระเบียบและถูกต้องตามหลักกฎหมาย PDPA เราตัดสินใจติดตั้งกล่องกดยอมรับข้อตกลงความเป็นส่วนตัว (PDPA Consent Checkbox) ในแบบฟอร์มลงทะเบียนออนไลน์ โดยระบุวัตถุประสงค์ในการเก็บและประมวลผลข้อมูลส่วนบุคคลสำหรับการติดต่อประชาสัมพันธ์งานสัมมนาในอนาคต ทำให้ระบบสามารถจัดเก็บข้อมูลผู้ลงทะเบียนไว้ได้ตลอดไป (Indefinite Data Retention) โดยไม่มีนโยบายลบข้อมูลส่วนตัวอัตโนมัติหลังจบงาน

## Status
accepted

## Considered Options
- **Strict Auto-Purge**: ลบข้อมูลส่วนตัวทิ้งหลังจบงานสัมมนาภายใน 30 วัน (ขัดต่อวัตถุประสงค์ในการใช้ข้อมูลทำการตลาดต่องานปีถัดไป)
- **Simple Register (No Consent)**: ลงทะเบียนแบบปกติแต่ไม่มีกล่องยินยอม (มีความเสี่ยงทางกฎหมายสูงมาก)
- **Consent with Indefinite Retention (Selected)**: แจ้งคำชี้แจงยินยอมอย่างชัดเจนในฟอร์ม และจัดเก็บข้อมูลอย่างปลอดภัยโดยไม่มีการลบ เพื่อการประชาสัมพันธ์และติดต่อในอนาคตตามขอบเขตความยินยอม
