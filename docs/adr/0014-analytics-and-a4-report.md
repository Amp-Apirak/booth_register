# 0014-analytics-and-a4-report

แท็บ "รายงานและกราฟ" (`/dashboard?tab=analytics`) คำนวณในเบราว์เซอร์จากรายชื่อที่ Dashboard โหลดอยู่แล้ว (อัปเดตสดผ่าน `participants:update`) + ประเภทองค์กร + รายชื่อผู้ได้รางวัล ไม่มี API ใหม่ · ปุ่ม **พิมพ์รายงาน A4** เปิด `/dashboard/report?…` (ส่งตัวกรองชุดเดียวกันใน URL) แล้วพิมพ์หรือบันทึก PDF ด้วยเบราว์เซอร์

**เหตุผล:**
1. ข้อมูลงานหนึ่งมีหลักร้อยถึงหลักพันแถว คำนวณในเบราว์เซอร์ได้ทันทีและกรองโต้ตอบได้ไม่ต้องรอ server · ฟังก์ชันคำนวณอยู่ใน `client/src/lib/analytics.ts` (pure function มี unit test)
2. กราฟกรองไขว้กัน: คลิกกราฟหนึ่งแล้วกราฟอื่นกรองตาม แต่กราฟที่ถูกคลิกไม่กรองตัวเอง (ไฮไลต์ส่วนที่เลือกแทน) จึงยังเห็นภาพรวมและเลือกเพิ่มได้
3. "มิติ 3D" ทำด้วยความลึก เงา และการเอียงการ์ด (แท่งนูน, แถบสัดส่วนแบบแผ่นหนา) **ไม่ใช้พายหรือแท่ง 3D แบบมุมมองเอียง** เพราะทำให้อ่านค่าผิด · ทุกกราฟมีปุ่ม "ดูตาราง", แกนเดียว, ใช้ชุดสีที่ตรวจแล้ว ([ADR-0012](0012-organization-types.md))
4. รายงานพิมพ์ด้วย CSS (`@page`) ไม่ใช้ไลบรารี PDF: กระดาษ A4 แนวตั้ง ขอบตามแบบหนังสือราชการไทย บน 2.5 ซม. ล่าง 2 ซม. ซ้าย 3 ซม. ขวา 2 ซม. · ฟอนต์ Sarabun · เลขหน้า "หน้า X / Y" · หัวตารางซ้ำเมื่อขึ้นหน้าใหม่ · มีช่องลงนามผู้จัดทำ/ผู้ตรวจสอบ
5. รายงานมีเฉพาะตัวเลขสรุป ไม่มีข้อมูลส่วนบุคคลรายคน (PDPA) นำไปแนบหนังสือให้หน่วยงานได้

**ผลกระทบ:**
- ถ้างานมีผู้ลงทะเบียนหลายหมื่นคนขึ้นไป ให้ย้ายการรวมตัวเลขไปทำใน SQL
- เวลาในกราฟใช้เขตเวลาของเครื่องที่เปิด (ควรตั้ง Asia/Bangkok)
- พิมพ์ให้ตั้ง Scale 100% และปิด "Headers and footers" ของเบราว์เซอร์ มิฉะนั้นขอบและเลขหน้าจะไม่ตรง
- กราฟ/ตารางใหม่ในรายงาน: เพิ่มฟังก์ชันใน `analytics.ts` + test แล้วใช้ทั้งใน `AnalyticsPanel.tsx` และ `AnalyticsReport.tsx`
