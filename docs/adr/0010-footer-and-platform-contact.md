# 0010-footer-and-platform-contact

Footer มี 3 แบบตามผู้ใช้หน้า: หน้าผู้เข้าร่วม (เต็ม), หน้าเจ้าหน้าที่ `/dashboard` `/settings` (บรรทัดเดียว), หน้าจอแสดงผล `/signage` `/lucky-draw` `/scanner` (ไม่มี) ข้อมูลของ **งาน** (ผู้จัด, ติดต่อ, แผนที่, นโยบาย PDPA) มาจากตั้งค่าระบบ ส่วนข้อมูลติดต่อ **เจ้าของแพลตฟอร์ม** อยู่ในโค้ด `client/src/lib/platform.ts`

**เหตุผล:**
1. ผู้เข้าร่วมต้องหาช่องทางช่วยเหลือ (ตั๋วหาย/ไม่ได้รับอีเมล) และอ่านนโยบายความเป็นส่วนตัวได้ทุกหน้า (สอดคล้อง ADR-0005 PDPA)
2. จอ LED/kiosk เปิดเต็มจอ footer จะกินพื้นที่และดันเนื้อหาเลยขอบ
3. ข้อมูลติดต่อแพลตฟอร์ม (ผู้ขาย) ต้องเหมือนกันทุกงานและไม่ควรให้ผู้จัดงานแต่ละรายแก้/ลบได้

**ผลกระทบ:**
- เพิ่ม settings key: `organizer_name`, `contact_phone`, `contact_email`, `contact_line`, `event_map_url` (ต้องเป็น http/https), `privacy_policy` · หน้าใหม่ `/privacy`
- เปลี่ยนผู้ติดต่อแพลตฟอร์ม = แก้ `platform.ts` แล้ว deploy ใหม่
- เนื้อหานโยบายความเป็นส่วนตัวต้องมาจากผู้จัดงาน/ฝ่ายกฎหมาย ระบบมีเพียงช่องกรอกและหน้าแสดงผล
