# Queue-Based Event Streaming for Local-to-Cloud Sync

เพื่อส่งข้อมูลการเช็คอินที่เก็บบันทึกบน Local Node ขึ้นฐานข้อมูลคลาวด์กลาง (PostgreSQL) ได้อย่างถูกต้องและไม่มีสูญหายเมื่อสัญญาณอินเทอร์เน็ตหน้างานกลับมาทำงาน เราตัดสินใจใช้สถาปัตยกรรม Queue-Based Event Streaming (FIFO Queue) บนหน่วยเก็บข้อมูลท้องถิ่นของ Local Node และจะค่อยๆ ทยอยคิวส่งขึ้นคลาวด์ทีละรายการ

## Status
accepted

## Considered Options
- **Bulk Synchronization**: ส่งข้อมูลเป็นก้อนใหญ่พร้อมๆ กัน ประหยัดแบนด์วิดท์แต่มีความเสี่ยงข้อมูลขาดตอนเมื่อเน็ตดับกลางคัน
- **Real-time Sync Only**: ซิงค์เฉพาะตอนออนไลน์ ทำให้สถิติช่วงเน็ตหลุดไม่แสดงบนคลาวด์หลัก (ข้อมูลไม่สมบูรณ์)
- **Queue-Based Event Streaming (Selected)**: ใช้ SQLite/NeDB เก็บคิวในเครื่องและส่งแบบเรียงลำดับ ปลอดภัยและถูกต้องที่สุด
