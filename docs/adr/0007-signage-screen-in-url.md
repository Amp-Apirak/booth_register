# 0007-signage-screen-in-url

แต่ละจอ LED เลือกหน้าที่จะแสดงผ่าน URL (`/signage?screen=welcome|overview|agenda|lucky`) และ **จะไม่เปลี่ยนหน้าเอง** เมื่อมีเหตุการณ์เข้ามา

**เหตุผล (Context & Reasons):**
1. หน้างานจริงใช้หลายจอพร้อมกัน เช่น จอต้อนรับที่ประตู จอตัวเลขในห้องสตาฟ จอเวที โดยเปิด URL เดียวค้างไว้บนแต่ละจอ
2. เดิมเมื่อมีคนเช็คอิน ทุกจอเด้งไปหน้า Welcome ทำให้จอ Overview ในห้องสตาฟหายไป (ผู้ใช้แจ้ง 2026-09-23)
3. URL ทำให้รีเฟรชหรือรีสตาร์ทเครื่องแล้วกลับมาหน้าเดิม และส่งลิงก์ให้ทีมติดตั้งจอได้ตรง ๆ

**ผลกระทบ (Consequences):**
- ข้อมูลยังอัปเดตสดทุกจอผ่าน WebSocket แต่พลุ/แอนิเมชันเล่นเฉพาะจอที่เกี่ยวข้อง (Welcome เมื่อเช็คอิน, Lucky เมื่อประกาศผู้โชคดี)
- event `signage:layout_change` ในสเปกเดิมยังไม่ได้ทำ หากต้องการสั่งสลับจอจากศูนย์กลางในอนาคต ให้ส่ง event แล้วให้จอเปลี่ยน URL (`router.replace`) แทนการเก็บ state ในหน้า
- หน้า `/settings?tab=...` ใช้แนวทางเดียวกันเพื่อให้รีเฟรชแล้วอยู่แท็บเดิม
