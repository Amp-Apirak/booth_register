# Multi-Channel Winner Notification for Lucky Draw

เพื่อให้ผู้ได้รับรางวัลทราบผลการสุ่มตัวอย่างทันท่วงทีแม้ว่าจะเดินอยู่นอกห้องสัมมนาหลัก เราตัดสินใจเชื่อมต่อระบบสุ่มจับรางวัล (Lucky Draw Engine) เข้ากับช่องทางการแจ้งเตือน SMS Gateway และ Email Service เพื่อยิงส่งข้อความเตือนให้ผู้ชนะมารายงานตัวที่เคาน์เตอร์ภายในเวลาที่กำหนด

## Status
accepted

## Considered Options
- **Screen-Only Display**: แสดงผลเฉพาะบนจอใหญ่ LED หน้างานอย่างเดียว หากไม่อยู่ถือว่าสละสิทธิ์และกดสุ่มใหม่
- **Email Notification Only**: ช้าและผู้ร่วมงานอาจไม่สังเกตเห็น
- **Multi-Channel Alert (Selected)**: ส่งทั้ง SMS และ Email พร้อมกันเพื่อความสะดวกรวดเร็วและลดโอกาสการสละสิทธิ์โดยไม่ได้ตั้งใจ
