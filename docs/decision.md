## การตัดสินใจเล็ก ๆ ที่ไม่ได้ทำ ADR

| วันที่ | เรื่อง | การตัดสินใจ |
|---|---|---|
| 2026-09-25 | เมนูบน | แถบเมนูเต็มเริ่มที่จอ ≥1280px (ต่ำกว่านั้นใช้ปุ่มเมนู) · เจ้าหน้าที่มี 8 เมนูจึงใช้แถบกะทัดรัดไม่มีไอคอน ให้อยู่แถวเดียวทั้งไทยและอังกฤษ |
| 2026-09-25 | หน้า Dashboard | กว้างสุด 1600px เท่าแถบเมนู (หน้าอื่น 1280px) · คอลัมน์ "จัดการ" ติดขอบขวาเมื่อจอแคบจนตารางต้องเลื่อน |
| 2026-09-25 | เรียงคอลัมน์ประเภทองค์กร | เรียงตามลำดับที่ตั้งไว้ในหน้าตั้งค่า แล้วตามด้วย "อื่นๆ" และ "ไม่ระบุ" |
| 2026-09-25 | ช่องประเภทองค์กรในหน้าลงทะเบียน | ใช้ dropdown แบบ `<select>` ของเบราว์เซอร์ (เจ้าของระบบเลือกแทนการ์ด) — กะทัดรัด, มือถือเปิดตัวเลือกของเครื่อง · ตรวจช่องว่างด้วยข้อความของระบบ (ไม่ใช้ `required` ของเบราว์เซอร์ เพื่อให้ข้อความตรงภาษา) |
| 2026-09-25 | รูปตั๋ว/QR ที่บันทึกลงเครื่อง | รูปจากหน้าลงทะเบียน/หน้าตั๋วใช้พื้นตามธีมที่เปิดอยู่ · การ์ด QR ในแดชบอร์ดขาวเสมอ · ตอนแปลงเป็นรูปตัดระยะขอบ (margin) ของการ์ดทิ้งเสมอ มิฉะนั้นรูปเยื้อง |
